## 📱 Ejecución en Emulador de Android

```powershell
cd app_sesion_06
flutter emulators --launch Medium_Phone_2
flutter run -d android
```

### Atajos en Terminal:
* `r`: Hot Reload
* `R`: Hot Restart
* `p`: Debug Paint Size (Líneas de depuración de layout)
* `q`: Salir
